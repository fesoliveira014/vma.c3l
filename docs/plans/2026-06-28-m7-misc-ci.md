## Global Constraints

- **C3 0.8.0.** Externs use `@cname("vmaXxx")`, NOT `@extern`. Allocator-first functions are methods with receiver `self` **by value** (handle is `inline void*`). Lift a fault with trailing `~`; propagate with `!`. `T::size`, never `T.sizeof`. `size_t` → `usz`.
- **All Vulkan types come from `vk`** (`vk::DeviceSize`, `vk::Result`, `vk::Bool32`, `vk::Buffer`, `vk::Image`, `vk::BufferCreateInfo`, `vk::ImageCreateInfo`, `vk::MemoryRequirements`, `vk::MemoryPropertyFlags`). Never redefine them.
- **Reuse, don't redefine:** `AllocationInfo`/`AllocationCreateInfo`/`BufferAllocation` (M1), `check()` + `CORRUPTION_DETECTED` + `BATCH_LENGTH_MISMATCH` (M3/M4). `vma.c3` is unchanged.
- **`vmaCheckCorruption` returns `VkResult`**; its idiomatic wrapper maps `VK_ERROR_UNKNOWN`→`CORRUPTION_DETECTED` locally (NOT via the shared `check()`), `SUCCESS`→ok, else `check()` — the same shape as M4's `try_check_pool_corruption`.
- **One new layout-pinned struct:** `$assert(AllocationInfo2::size == 72)`.
- **The `create_aliasing_*2` variants are bound raw, compile-checked only** (the M2 `*2` norm); their primaries are runtime-tested.
- **CI builds linux-x64 + windows-x64 only**, uploads libs as **artifacts** (not auto-committed). The windows lib links only once its CI artifact is committed to `linked-libs/windows-x64/` — documented, not done here.
- **Naming:** types PascalCase, functions/fields snake_case, faults one-per-line, named constants (test fixtures exempt), no `@builtin`, no all-uppercase type names. K&R braces. Do not run `c3fmt`. **`alias` is a C3 keyword — never use it as a variable name** (use `alias_buf` etc.).
- **No milestone tags in code or comments.** `(M7)` may appear in commit messages only.

```c3
module vma;

import vk;

<* Check default-pool corruption for the given memory types. Returns normally on
   SUCCESS or (accepted) FEATURE_NOT_PRESENT when detection is off; raises
   CORRUPTION_DETECTED when corruption is found (VMA reports it as VK_ERROR_UNKNOWN). *>
fn void? Allocator.try_check_corruption(self, uint memory_type_bits) {
    vk::Result r = self.check_corruption(memory_type_bits);
    switch (r) {
        case vk::Result.SUCCESS:       return;
        case vk::Result.ERROR_UNKNOWN: return CORRUPTION_DETECTED~;
        default:                       check(r)!;
    }
}

fn vk::MemoryPropertyFlags Allocator.allocation_memory_properties(self, Allocation allocation) {
    vk::MemoryPropertyFlags out_flags;
    self.get_allocation_memory_properties(allocation, &out_flags);
    return out_flags;
}

fn AllocationInfo2 Allocator.allocation_info2(self, Allocation allocation) {
    AllocationInfo2 out_info;
    self.get_allocation_info2(allocation, &out_info);
    return out_info;
}

fn vk::Buffer? Allocator.try_create_aliasing_buffer(self, Allocation allocation, vk::BufferCreateInfo* bi) {
    vk::Buffer out_buffer;
    check(self.create_aliasing_buffer(allocation, bi, &out_buffer))!;
    return out_buffer;
}

fn vk::Image? Allocator.try_create_aliasing_image(self, Allocation allocation, vk::ImageCreateInfo* ii) {
    vk::Image out_image;
    check(self.create_aliasing_image(allocation, ii, &out_image))!;
    return out_image;
}

fn BufferAllocation? Allocator.try_create_buffer_with_alignment(self, vk::BufferCreateInfo* bi, AllocationCreateInfo* ci, vk::DeviceSize min_alignment) {
    BufferAllocation ba;
    check(self.create_buffer_with_alignment(bi, ci, min_alignment, &ba.buffer, &ba.allocation, &ba.info))!;
    return ba;
}

<* Allocate a batch of pages, one per (reqs, cis) pair. All three slices must be the
   same nonzero length; results land in out_allocs. Free with free_memory_pages. *>
fn void? Allocator.try_allocate_memory_pages(self, vk::MemoryRequirements[] reqs, AllocationCreateInfo[] cis, Allocation[] out_allocs) {
    if (reqs.len != cis.len || reqs.len != out_allocs.len) return BATCH_LENGTH_MISMATCH~;
    if (out_allocs.len == 0) return;
    check(self.allocate_memory_pages(&reqs[0], &cis[0], (usz)out_allocs.len, &out_allocs[0], null))!;
}
```

```c3

<* Exercise the misc leftovers: frame index, allocation name/user-data round-trip,
   memory properties, info2, corruption check, buffer-with-alignment, memory pages,
   and an aliasing buffer. *>
fn void? misc_round_trip(vma::Allocator alloc, vk::Device device) {
    alloc.set_current_frame_index(0);

    vk::BufferCreateInfo bi = {
        .s_type       = vk::StructureType.BUFFER_CREATE_INFO,
        .size         = BUFFER_SIZE,
        .usage        = vk::BufferUsageFlagBits.TRANSFER_DST_BIT,
        .sharing_mode = vk::SharingMode.EXCLUSIVE,
    };
    vma::AllocationCreateInfo ai = {
        .usage = vma::MemoryUsage.AUTO,
        .flags = { .host_access_random = true },
    };
    vma::BufferAllocation ba = alloc.try_create_buffer(&bi, &ai)!;
    defer alloc.destroy_buffer(ba.buffer, ba.allocation);

    alloc.set_allocation_name(ba.allocation, "smoke_alloc");
    vma::AllocationInfo ni;
    alloc.get_allocation_info(ba.allocation, &ni);
    if (ni.name.str_view() != "smoke_alloc") return MISC_NAME_MISMATCH~;

    int marker = 7;
    alloc.set_allocation_user_data(ba.allocation, &marker);
    vma::AllocationInfo ui;
    alloc.get_allocation_info(ba.allocation, &ui);
    if (ui.user_data != (void*)&marker) return MISC_USERDATA_MISMATCH~;

    vk::MemoryPropertyFlags mp = alloc.allocation_memory_properties(ba.allocation);
    if (((uint)mp & (uint)vk::MemoryPropertyFlagBits.HOST_VISIBLE_BIT) == 0) return MISC_MEMPROPS~;

    vma::AllocationInfo2 i2 = alloc.allocation_info2(ba.allocation);
    if (i2.allocation_info.size < BUFFER_SIZE) return MISC_INFO2~;
    if (i2.block_size < i2.allocation_info.size) return MISC_INFO2~;

    if (catch err = alloc.try_check_corruption(0xFFFFFFFF)) {
        if (err != vma::FEATURE_NOT_PRESENT) return err~;
    }

    vma::BufferAllocation aba = alloc.try_create_buffer_with_alignment(&bi, &ai, MISC_ALIGN_REQ)!;
    defer alloc.destroy_buffer(aba.buffer, aba.allocation);
    if (aba.info.offset % MISC_ALIGN_REQ != 0) return MISC_ALIGN~;

    vk::BufferCreateInfo pbi = {
        .s_type       = vk::StructureType.BUFFER_CREATE_INFO,
        .size         = PAGE_SIZE,
        .usage        = vk::BufferUsageFlagBits.TRANSFER_SRC_BIT,
        .sharing_mode = vk::SharingMode.EXCLUSIVE,
    };
    vk::Buffer probe;
    if (vk::create_buffer(device, &pbi, null, &probe) != vk::Result.SUCCESS) return BUFFER_NULL~;
    vk::MemoryRequirements one;
    vk::get_buffer_memory_requirements(device, probe, &one);
    vk::destroy_buffer(device, probe, null);

    vk::MemoryRequirements[PAGE_COUNT]   reqs;
    vma::AllocationCreateInfo[PAGE_COUNT] cis;
    vma::Allocation[PAGE_COUNT]          pages;
    for (uint i = 0; i < PAGE_COUNT; i++) {
        reqs[i] = one;
        cis[i] = { .usage = vma::MemoryUsage.GPU_ONLY };
    }
    alloc.try_allocate_memory_pages(&reqs, &cis, &pages)!;
    alloc.free_memory_pages(PAGE_COUNT, &pages[0]);

    vk::Buffer alias_buf = alloc.try_create_aliasing_buffer(ba.allocation, &bi)!;
    vk::destroy_buffer(device, alias_buf, null);
}
```

Notes for the implementer: `alias` is a C3 keyword, hence `alias_buf`. `BUFFER_NULL` is an existing fault from earlier milestones (reused for the probe-buffer create). The aliasing buffer is destroyed with `vk::destroy_buffer` (VMA did not allocate its memory — it aliases `ba`'s), and must be destroyed before `ba` (the `defer` for `ba` runs at function end, after this line — correct order).

name: build-vma-libs

# CI cross-build (linux-x64, windows-x64)

The `.github/workflows/build-vma-libs.yml` workflow compiles the VMA static lib
(`scripts/vma_impl.cpp`, the same impl TU used locally) for two targets and uploads
each as a build artifact:

- `libVulkanMemoryAllocator-linux-x64` → `libVulkanMemoryAllocator.a`
- `VulkanMemoryAllocator-windows-x64` → `VulkanMemoryAllocator.lib`

It runs on manual dispatch (Actions → "build-vma-libs" → Run workflow) and on pushes
that touch `scripts/vma_impl.cpp`, `scripts/vma_size_probe.cpp`, or the workflow
itself. It requires a GitHub remote — it does not run from a local-only checkout.

Header versions are pinned via the `VMA_TAG` / `VULKAN_HEADERS_TAG` env vars; bump
them together when updating VMA.

## Enabling the windows target

The `windows-x64` manifest target is already wired (`dependencies: ["vk"]`,
`linked-libraries: ["VulkanMemoryAllocator"]`), but the lib itself is an artifact, not
committed. To make a windows consumer link:

1. Run the workflow and download the `VulkanMemoryAllocator-windows-x64` artifact.
2. Commit `VulkanMemoryAllocator.lib` to `linked-libs/windows-x64/`.
3. Windows consumers of `vma` then link it the same way linux-x64 already does.

The linux-x64 lib is already built and committed (`linked-libs/linux-x64/`); the
workflow can refresh it (download the linux artifact and replace the committed `.a`).

## Binding surface

the build (`vmaGetMemoryWin32Handle` — needs `VMA_EXTERNAL_MEMORY_WIN32`; and
`vmaImportVulkanFunctionsFromVolk` — volk integration). The other 13 manifest targets
beyond linux-x64/windows-x64 are not yet populated.
